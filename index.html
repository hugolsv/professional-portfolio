-- Illustrative pattern only: generic table names, no client data
SELECT i.account_id,
       i.invoice_id,
       i.net_amount,
       DAYS(CURRENT DATE) - DAYS(i.expected_bill_date) AS days_delayed
FROM   invoices i
JOIN   contracts c ON c.contract_id = i.contract_id
WHERE  i.status = 'PENDING'
  AND  c.financing_flag = 'Y'
  AND  i.expected_bill_date < CURRENT DATE - 30 DAYS
ORDER BY days_delayed DESC;

Shows the type of logic used to surface delayed invoices; not production code.
